Plataforma de API open source: documentación, cliente REST, registry de OpenAPI y generación de SDKs, todo a partir de la spec. Alternativa moderna al combo Postman + Swagger UI + generador de clientes.

## Por qué vale la pena

- **API Reference / Docs**: soporta Markdown, MDX, OpenAPI y AsyncAPI, con sync bidireccional con Git (la doc vive en el repo, no en una UI).
- **API Client**: alternativa a Postman, open source y offline-first, construida sobre OpenAPI en vez de un formato propietario.
- **SDK Generator**: clientes type-safe para TypeScript, Python, Go, PHP, Java y Ruby desde el documento OpenAPI.
- **API Registry**: versiona y administra documentos OpenAPI con integración Git.
- **Embebible**: el componente de reference se mete en cualquier app y tiene integraciones para frameworks de backend, que es el uso más común (reemplazar Swagger UI en un servicio existente).

## Uso básico

Repo monorepo en `github.com/scalar/scalar`; el producto hosteado y los planes están en <https://scalar.com>. Las features open source son gratis.
