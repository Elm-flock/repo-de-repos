La lista original de "awesome lists": un índice de ~700 listas curadas por tema, de lenguajes y frameworks a seguridad, hardware o libros. La creó Sindre Sorhus en julio de 2014 y es el origen del formato y del badge "Awesome" que usan las demás. Es el punto de partida para buscar la lista de referencia de cualquier tema antes de ponerse a googlear.

## Por qué vale la pena

- **Escala**: ~510k estrellas, ~37k forks y 27 categorías (Platforms, Programming Languages, Front-End, Back-End, Databases, Security, Testing, Hardware, Learn, etc.).
- **Filtro de calidad real para entrar**: la lista propuesta tiene que tener 30+ días de vida, pasar `awesome-lint`, no ser generada por IA y usar `main` como branch. Además, quien la propone tiene que revisar al menos 4 PRs abiertos de otros. No se aceptan listas de blockchain.
- **IA cubierta**: Machine Learning, Deep Learning, Generative AI, Artificial Intelligence, ChatGPT, Prompt Injection, Copilot Agents y Claude Code (`hesreallyhim/awesome-claude-code`).
- **Ecosistema alrededor**: `awesome-lint` para validar una lista propia, awesomelists.top para buscar entre todas, trackawesomelist.com para ver qué cambió, `awesome-cli` para navegarlas desde la terminal.

## Advertencia

Los PRs están deshabilitados temporalmente (lo dice la descripción del repo) hasta que se ponga al día con los pendientes. Las listas nuevas, como las de agentes o MCP, pueden tardar en aparecer o no estar. Para Claude hay una lista más específica: [[awesome-claude]].

## Uso básico

Navegar el `readme.md` por categoría. Para armar una lista propia con el formato:

```bash
npx awesome-lint            # valida el README de la lista en el directorio actual
```
