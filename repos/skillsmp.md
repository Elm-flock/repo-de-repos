Marketplace / directorio para descubrir Agent Skills. Buscador con filtros por keyword, categoría, autor, popularidad y ocupación, sobre skills de Claude Code, Codex CLI y ChatGPT.

## Por qué vale la pena

- **Resuelve el problema de descubrimiento**: las skills están desparramadas en repos sueltos y gists; acá hay un índice con búsqueda.
- **Filtros útiles para elegir**: lenguaje, ocupación, dominio, categoría y recencia del update — este último importa porque una skill sin mantener envejece rápido.
- **Selecciones curadas** por interacción de usuarios y calidad de la fuente (incluye skills de Anthropic).
- **Cubre los tres agentes** que usa el equipo: Claude Code, Codex y ChatGPT.
- Tiene versión en español (`/es/search`).

## Uso básico

<https://skillsmp.com/es/search>. Las skills son de autores variados: verificar licencia y contenido de cada una antes de instalarla — es código que corre en tu máquina con el contexto de tu proyecto.

Relacionado: [[hallmark]], [[caveman]] y [[graph-engineer]] son skills que ya están en este repo.
