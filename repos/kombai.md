Agente de IA especializado en frontend ("AI design engineer"): diseña en un canvas infinito, genera código production-ready integrado a tu codebase y deja editar visualmente la UI ya renderizada, todo en el mismo loop.

## Por qué vale la pena

- **Tuneado para lo que los agentes generalistas hacen mal**: el frontend. Trae documentación y best practices embebidas de 400+ librerías del stack frontend.
- **"Design = Code"**: los diseños del canvas son HTML renderizado, no una imagen que después alguien traduce a mano. Canvas, código y browser sincronizados en tiempo real.
- **Integración nativa con Figma** (parsea el archivo) más reuso de componentes desde paquetes npm y Storybook, y sistemas de design tokens.
- **Context Graphs** para entendimiento semántico del codebase, y modos dedicados de debug y planning para tareas de frontend.
- **Editor visual en browser**: cambios de texto, estilo y layout directo sobre la UI renderizada.
- **Precio**: free tier de 300 créditos/mes, planes desde USD 20/mes. Soporta MCP.

## Uso básico

Extensión para VS Code, Cursor y otros IDEs desde los marketplaces, o directo en <https://kombai.com>.
